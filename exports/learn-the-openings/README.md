# Export des ouvertures Chess.com

Source : [Learn Every Chess Opening](https://www.chess.com/lessons/learn-the-openings).

50/50 leçons extraites, 500 exercices, 5166 commentaires et 2084 coups dans les lignes principales compilées.

Chaque dossier conserve les données intégrées à la page dans `source.json`, tous les exercices et variantes dans `exercises.pgn`, et une version structurée pour le lecteur dans `playback.json`. Les avertissements ou exercices non compilables sont recensés ; le PGN source reste conservé intégralement.

Les textes sont conservés dans la langue de la page source. Les références vidéo sont conservées comme métadonnées ; les fichiers vidéo et leur narration ne sont pas exportés. Les exercices ne représentent donc pas nécessairement tout le contenu théorique présenté dans la vidéo.

La bibliothèque et le répertoire de chess-analysis ne sont pas modifiés par cet export.
