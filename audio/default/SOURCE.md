# Default — Chess.com

Fichiers MP3 provenant de la copie publique suivante :
https://github.com/Orivoir/scraping-sound-effects-chess.com/tree/main/assets/default

Origine annoncée par ce dépôt : banque Default de Chess.com.
Import : 22 octobre 2026. Les fichiers ont été conservés sans transformation.

Cette source contient les sons des coups, prises, roques, promotions, échecs,
coups illégaux, débuts et fins de partie ainsi que quelques notifications.
Elle ne contient pas les voix du coach ni les sons spécifiques `correct`,
`incorrect` et `lesson_pass`. Le lecteur utilise `illegal` pour une tentative
refusée et `game-end` pour marquer une fin d’exercice.

Aucune licence de redistribution des sons n’est fournie dans ce dépôt source.
Les sons ne sont pas placés sous la licence du code de cet atelier.
